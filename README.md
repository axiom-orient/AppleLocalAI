# AppleLocalAI

Apple Foundation Models와 선택형 로컬 모델을 위한 Swift SDK입니다.

- 기본 SDK: iOS/macOS 27+, Xcode 27, Swift 6.4
- 시스템 모델 전용 패키지: OS 26+
- macOS 앱·Provider·Console: `Platforms/macOS/`

검증 상태와 미완료 항목은 [`docs/VERIFICATION.md`](docs/VERIFICATION.md)에서 확인할 수 있습니다.

AppleLocalAI 자체의 재사용 라이선스는 제공하지 않습니다. 제3자 코드의 고지와 조건은 [`NOTICE`](NOTICE)와 [`LICENSES/`](LICENSES/)에 있습니다.
